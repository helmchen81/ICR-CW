# ICR-CW
ICR tool trains instant mental recognition without counting dits/dahs for morse code

It archives following functions:


Instant Character Recognition (ICR) & PARIS Standard

ICR trains instant mental recognition without counting dits/dahs. Under the PARIS standard (1 word = 50 dits), 1 dit duration is 1200 / WPM ms. Standard inter-character space equals 3 dits (3600 / WPM ms).
Game Modes

Time Attack Mode: Practice for a set duration (1 to 10 minutes) and maximize your score.
Arcade Mode (5 Lives): Start with 5 lives. Each mistake or timeout costs 1 life.
Speed (WPM) & Auto-Calculated Timings

Adjusting WPM calculates the exact standard inter-character space for the ICR Target Time (e.g., 35 WPM = 103 ms) and sets TTS Delay 300 ms above it. Both sliders remain fully adjustable.
Scoring & Streaks

Correct responses within the ICR Target Time yield maximum points. Answering before timeout awards partial points. Consecutive correct answers build up a Streak Multiplier (up to 3.0x).
Text-To-Speech (TTS) Assistance

If you fail to type a character within the TTS delay or make a mistake, the system speaks the correct character in the selected language to reinforce learning.
Static QRM (White Noise)

Simulates real-world radio conditions by adding adjustable background white noise to improve noise immunity during practice.
Weak Characters Retry Mode

After a round, click 🔥 New Run with Weak Characters to launch a session where characters with high reaction times or errors appear with 3x higher probability.

Currently, highscore is only localy stored.
