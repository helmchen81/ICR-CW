User Guide & Features

Instant Character Recognition (ICR) & PARIS Standard

ICR trains instant mental recognition without counting dits/dahs. Under the PARIS standard (1 word = 50 dits), 1 dit duration is 1200 / WPM ms. Standard inter-character space equals 3 dits (3600 / WPM ms).

Game Modes

Time: Practice for a set duration (1 to 10 minutes) and maximize your score.
Battle: Start with 5 lives. Each mistake or timeout costs 1 life.
Listen: Pure listening practice. Plays Morse sound, pauses for ICR recognition time, reveals letter and speaks it via TTS automatically without keypresses or scoring.

Key Hit Delay & Combined Target Time

Recognizing a character is mental; pressing the key is motor-physical. Key Hit Delay accounts for your physical motor reaction time (typically ~200 ms). Total target duration for full points equals ICR Mental Target + Key Hit Delay.

Scoring & Streaks

Correct responses within the Combined Target Time yield maximum points. Answering before timeout awards partial points. Consecutive correct answers build up a Streak Multiplier (up to 3.0x).

Text-To-Speech (TTS) Assistance

If you fail to type a character within the TTS delay or make a mistake, the system speaks the correct character in the selected language using phonetic letter-name mapping to reinforce learning.

Static QRM (White Noise)

Simulates real-world radio conditions by adding adjustable background white noise to improve noise immunity during practice.
